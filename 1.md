🪄 1️⃣ Splash Screen
🧩 Purpose

Display app branding while loading configuration (theme, language, session token).

💡 Design

Duration: 2–3 seconds

Background color: #0C3C49 (Deep teal)

Logo animation: Tea logo fade-in or shimmer

Tagline (optional): “Safe. Supportive. Together.”

Progress Indicator: Minimal circular loader or shimmer

⚙️ Logic

Check AsyncStorage for existing access_token.

If exists → navigate to Home screen.

If not → go to Onboarding screens.

🔐 3️⃣ Login / Signup System
💡 Purpose

Authenticate users securely with Laravel backend via Sanctum API.

📱 Screens
🔸 Login Screen

Email / Phone input

Password input (hidden)

“Forgot Password?” link

Button: Login

Secondary text: “Don’t have an account? Sign up”

🔸 Signup Screen

Name

Email

Password (with validation)

Confirm Password

Checkbox: “I agree to the Terms of Use and Privacy Policy”

Button: Create Account

Secondary text: “Already have an account? Login”

🔸 Forgot Password

Email input → sends request to Laravel endpoint

Toast message: “If your email exists, you’ll receive a reset link.”

⚙️ Backend Integration
Action	API Endpoint	Method	Auth
Register	/api/v1/auth/register	POST	–
Login	/api/v1/auth/login	POST	–
Logout	/api/v1/auth/logout	POST	Token
Profile	/api/v1/profile	GET	Token

Login flow:

Submit credentials

On success → save access_token + user in AsyncStorage

Redirect to Home

On next app launch, Splash → detects token → auto-login

Logout flow:

Remove token from AsyncStorage

Call /logout

Navigate to Login screen

🧮 Validation Rules (Frontend)
Field	Rule
Email	Must match email regex
Password	≥ 8 chars, at least 1 letter
Name	Non-empty
Confirm Password	Must match password
Terms checkbox	Required
