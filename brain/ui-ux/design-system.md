# Tea App - Design System

## Brand Identity
**Tea** - A women-first social platform that creates a safe, supportive space for women to share experiences and build community.

## Color Palette
- **Primary**: Deep Teal `#0C3C49`
- **Accent**: Accent Green `#2D8C3C`
- **Background**: Off-white `#FAFAFA`
- **Neutral**: Beige `#F5F5DC`
- **Text**: Dark Gray `#333333`
- **Success**: Green `#4CAF50`
- **Warning**: Orange `#FF9800`
- **Error**: Red `#F44336`

## Typography
- **Primary Font**: Nunito (rounded, readable sans-serif)
- **Secondary Font**: Inter (clean, modern sans-serif)
- **Arabic Font**: Cairo (RTL-optimized)

### Font Sizes
- **Heading 1**: 32px (2rem)
- **Heading 2**: 24px (1.5rem)
- **Heading 3**: 20px (1.25rem)
- **Body**: 16px (1rem)
- **Caption**: 14px (0.875rem)
- **Small**: 12px (0.75rem)

## Spacing System
- **Base Unit**: 8px
- **Small**: 4px (0.5rem)
- **Medium**: 8px (1rem)
- **Large**: 16px (2rem)
- **Extra Large**: 24px (3rem)
- **Section**: 32px (4rem)

## Component Library

### Buttons
- **Primary**: Deep teal background, white text
- **Secondary**: White background, teal border
- **Danger**: Red background, white text
- **Ghost**: Transparent background, teal text

### Cards
- **Elevation**: Subtle shadow for depth
- **Border Radius**: 12px for modern look
- **Padding**: 16px internal spacing

### Input Fields
- **Border**: 1px solid light gray
- **Focus**: Teal border on focus
- **Error**: Red border for validation errors
- **Placeholder**: Light gray text

## Layout Principles

### Grid System
- **Mobile**: Single column layout
- **Tablet**: Two-column layout for larger screens
- **Spacing**: Consistent 16px margins

### Safe Areas
- **Top**: Status bar and notch consideration
- **Bottom**: Home indicator and tab bar
- **Sides**: Screen edge margins

## RTL Support
- **Layout**: Automatic layout flipping for Arabic
- **Icons**: Directional icons flip appropriately
- **Text**: Right-to-left text alignment
- **Navigation**: Tab order respects RTL

## Accessibility

### Color Contrast
- **Text**: Minimum 4.5:1 contrast ratio
- **Interactive**: Minimum 3:1 contrast ratio
- **Focus**: High contrast focus indicators

### Typography
- **Scaling**: Support for system font scaling
- **Line Height**: 1.5x for readability
- **Spacing**: Adequate spacing between elements

### Interactive Elements
- **Touch Targets**: Minimum 44px touch targets
- **Focus**: Clear focus indicators
- **States**: Hover, active, disabled states

## Animation Guidelines

### Transitions
- **Duration**: 200-300ms for most transitions
- **Easing**: Ease-in-out for natural feel
- **Performance**: 60fps target for smooth animations

### Micro-interactions
- **Button Press**: Subtle scale animation
- **Card Hover**: Gentle elevation change
- **Loading**: Smooth loading indicators

## Responsive Design

### Breakpoints
- **Mobile**: 320px - 768px
- **Tablet**: 768px - 1024px
- **Desktop**: 1024px+ (if web version)

### Adaptive Layout
- **Navigation**: Bottom tabs on mobile, sidebar on tablet
- **Content**: Single column on mobile, multi-column on tablet
- **Images**: Responsive sizing with aspect ratio preservation

## Mood & Tone
- **Warm**: Supportive, welcoming atmosphere
- **Safe**: Trustworthy, secure feeling
- **Modern**: Clean, contemporary design
- **Feminine**: Soft, approachable aesthetic
- **Professional**: Reliable, well-crafted appearance
