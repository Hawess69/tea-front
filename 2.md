UI/UX Layout Brief — Splash, Onboarding, Auth
Brand & Visual DNA

Mood: warm, safe, women-first, modern.

Palette: Deep teal #0C3C49 (primary), Accent green #2D8C3C, Soft cream #F9F6F2, Charcoal text #182022.

Type: Inter/Nunito, bold headlines, high legibility.

Corners & Shadows: 16–20px radius, soft ambient shadow.

Imagery: mix of soft gradients and women-centric illustrations/photos. Avoid stock “techy” look.

Global Bars & Elements

Top app bar (later reused across app): left Profile avatar, right Chat + Bell. For onboarding/auth, show only a minimal header with Skip when relevant.

Buttons: filled primary (deep teal) + large rounded; secondary ghost with teal border.

Inputs: rounded, large touch targets, left icons (mail/lock), clear labels + helper text.

Accessibility: min 44×44 touch, dynamic type friendly, contrast ≥ 4.5, TalkBack/VoiceOver labels.

Screens
1) Splash

Layout: Full-screen deep teal; centered Tea logo; small loading shimmer under logo.

Duration: 1.5–2.0s or until boot tasks finish.

States:

First-run (no token, no onboarding flag) → Onboarding

Has token → Home

No token but onboarding_done → Login

Micro-motion: logo fade-in (250ms), shimmer (infinite).

2) Onboarding (4 slides)

Structure: Horizontal pager with dots; “Skip” at top-right; bottom primary CTA (“Next” / “Get Started”).

Slides:

Welcome to Tea – “A safe community for women, by women.” (soft gradient + illustration)

Share Your Stories – “Post freely — control visibility & blur images.”

Discuss & Connect – “Reddit-style feed, forums & events.”

Stay Alert – “Get alerts when a name you track appears.”

Motion: Slide-in/slide-out with parallax on images (Reanimated), dot indicator morph.

RTL: pager direction reversed; “Skip” mirrors to top-left.

3) Auth Hub (optional landing)

Small screen that offers Log in / Create account. Can be skipped if you prefer direct Login.

4) Login

Header: “Welcome back 👋”

Inputs: Email/Phone, Password, “Forgot password?”

CTA: Log in (full width). Secondary text: “Don’t have an account? Sign up”.

Feedback: inline error below inputs; disable CTA while loading; toast on network error.

Social (later): placeholders under divider.

5) Signup

Header: “Create your account”

Inputs: Name, Email, Password, Confirm Password.

Checklist: password strength meter (weak/ok/strong).

Consent: checkbox “I agree to Terms & Privacy” (links open webview).

CTA: Create account. Footer: “Already have an account? Log in”.

6) Forgot Password

Copy: “Enter your email; we’ll send a reset link if it exists.”

CTA: Send reset link → success state with info panel.

Empty/Loading/Errors

Loading spinners with concise copy (“Checking your session…”).

Error panels: icon + one-line message + Retry.

i18n/RTL

All copy via keys.

Alignments and icon chevrons mirror with RTL.

Placeholder keys:

auth.login.title, auth.email, auth.password, auth.forgot, auth.signup.cta, etc.

onboard.1.title … onboard.4.subtitle.

Navigation Graph

 └─ Tabs (Main app)

State Machine (Auth)
BOOT → (read token, onboarding flag)
  ├─ token && valid → AUTHENTICATED → Tabs
  ├─ !token && !onboarding → ONBOARDING → set flag → LOGIN
  └─ !token && onboarding → LOGIN

AuthContext (minimal)
type User = { id: number; name: string; email?: string };
type AuthState = { user: User | null; token: string | null; loading: boolean };

const AuthContext = createContext<{
  state: AuthState;
  login: (payload: {email: string; password: string}) => Promise<void>;
  signup: (payload: {name: string; email: string; password: string}) => Promise<void>;
  logout: () => Promise<void>;
}>({...});


Auth flow

Splash reads token + onboarding_completed from AsyncStorage.

If token: call /api/v1/profile to validate (React Query).

login() → POST /api/v1/auth/login → save {token, user} → navigate Tabs.

signup() → POST /api/v1/auth/register → auto-login or redirect to Login.

logout() → clear storage + POST /auth/logout.

Storage keys

tea.token

tea.user

tea.onboarding_done

(later) tea.expoPushToken

Axios & API Client
export const api = axios.create({
  baseURL: process.env.EXPO_PUBLIC_API_URL,
  timeout: 15000,
});

api.interceptors.request.use(async (config) => {
  const token = await AsyncStorage.getItem('tea.token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

React Query setup

Query ['me'] for /profile after login.

Mutation keys: login, signup, requestReset.

Global error handler: map 401 to logout, show toast.

Forms & Validation

react-hook-form with zod schemas:

const loginSchema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
});


Show inline errors; disable CTA on submit; optimistic UI for fast feedback.

Onboarding Pager

Reanimated-powered horizontal pager with PanGestureHandler.

Store tea.onboarding_done = '1' at completion.

Error Handling & Edge Cases

Network offline → show banner + allow retry.

Invalid/expired token → clear + return to Login.

Rate-limit: disable auth CTAs for 2s after 3 failed attempts.

i18n & RTL

Initialize language from expo-localization.

I18nManager.allowRTL(true); flip icons/chevrons via scaleX: -1 when RTL.

All strings via keys; provide en.json, ar.json skeleton.

Accessibility

accessible labels on all inputs & buttons.

Password field announces “toggle visibility”.

“Skip” accessible label: “Skip onboarding”.

Analytics (optional)

Track events: onboarding_completed, login_success, signup_success, auth_error.

Testing Checklist

Splash: token/no-token paths.

Onboarding: swipe, skip, stored flag.

Login: good creds, bad creds, server 500, offline.

Signup: weak/strong password, duplicate email.

Forgot password: success & non-existent email.

RTL snapshot & interactive test (right-to-left pager).

Fast Refresh & deep linking (later).

Acceptance Criteria

Smooth <300ms transitions, 60fps on mid-range Android.

Pixel-parity light/dark themes.

Token persisted and restored; invalid token handled gracefully.

Full RTL & i18n ready.

Code modular, componentized, documented.
